# منصة حل كيريو التلقائي (Qureo Auto-Solver Platform)

نظام متكامل يتكون من:
1. **واجهة ويب سريعة وعصرية (Frontend):** متوافقة مع الموبايل والكمبيوتر ونظام الخطوات.
2. **سيرفر الطابور والمعالجة (Backend API):** مبني بـ FastAPI ويدير طابور الطلاب (Queue).
3. **محرك الأتمتة (Playwright Engine):** للتعامل مع متصفح كيريو الخفي.
4. **بنك الحلول (Solutions Bank):** ملف JSON يحتوي على أكواد المستويات الـ 42.

---

## 🚀 كيفية الرفع على استضافة (Deployment Guide):

### الخيار 1: استضافة مجانية عبر Render (موصى بها)
1. ارفع هذا المجلد بالكامل إلى حسابك على **GitHub** في مستودع جديد (Repository).
2. ادخل على [render.com](https://render.com) وأنشئ حساباً مجانياً.
3. اضغط على **New +** ثم اختر **Web Service**.
4. اربط مستودع GitHub الخاص بك.
5. في إعدادات البيئة (Runtime): اختر **Docker** (سيقرأ ملف `Dockerfile` تلقائياً لتثبيت المتصفح والسيرفر).
6. اضغط **Deploy Web Service**، وخلال دقيقتين سيعطيك رابطاً عاماً (`https://your-app.onrender.com`) يستطيع أي طالب الدخول إليه من هاتفه!

### الخيار 2: التشغيل على سيرفر VPS (Ubuntu / Linux)
```bash
# 1. الدخول لمجلد المشروع
cd qureo-solver-web

# 2. بناء وتشغيل حاوية Docker
docker build -t qureo-solver .
docker run -d -p 80:8000 --name qureo-bot qureo-solver
```
